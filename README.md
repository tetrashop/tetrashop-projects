# 🚀 TetraShop Projects – پلتفرم جامع فروشگاهی

**نسخه ۴.۲** | **آخرین بروزرسانی:** مرداد ۱۴۰۵

پروژهٔ `tetrashop-projects` یک مونورپوی بزرگ است که یک فروشگاه اینترنتی کامل (محصولات فیزیکی و دیجیتال) را به همراه ده‌ها سرویس جانبی شامل ربات‌های پیام‌رسان، موتورهای شطرنج، سامانه‌های پردازش زبان طبیعی، کیف پول ارزی، پنل مدیریت و ابزارهای مالی ارائه می‌دهد.

---

## 📄 چکیده

هدف این مخزن ایجاد یک اکوسیستم یکپارچه برای عرضهٔ کالاهای نرم‌افزاری و سخت‌افزاری، همراه با واسط‌های کاربری پیش‌نمایش (دموهای تعاملی) و قابلیت فروش مستقیم از طریق ربات بله می‌باشد.  
این مستند تمام جنبه‌های فنی، چالش‌های پیش‌آمده در فرایند توسعه، راه‌حل‌های اعمال‌شده و دستورالعمل‌های راه‌اندازی را به‌صورت علمی تشریح می‌کند.

## ✨ ماژول‌ها و ویژگی‌های کلیدی

### 🛍️ فروشگاه اصلی
- صفحات: اصلی، محصولات، جزئیات محصول، سبد خرید (Zustand)
- محصولات فیزیکی و دیجیتال (با دموهای HTML)
- جستجوی پیشرفته با فیلتر دسته‌بندی و بازه قیمت
- مقایسهٔ محصولات و علاقه‌مندی‌ها

### 🔐 احراز هویت
- ورود و ثبت‌نام کاربران (عمومی)
- پنل مدیریت با سطوح دسترسی (admin/manager)
- **ورود پیش‌فرض:** `admin` / `admin123` – `manager` / `manager123`

### 📊 پنل مدیریت
- داشبورد با وضعیت سرور و آمار
- مدیریت محصولات (افزودن، ویرایش، حذف) با CRUD کامل
- مدیریت کاربران (مشاهده، حذف)
- مشاهده و تأیید/رد سفارشات
- مدیریت تخفیف‌ها (کوپن‌های درصدی و ثابت)
- تیکت‌های پشتیبانی
- آنالیتیکس (بازدیدها، صفحات محبوب)
- تنظیمات سایت (نام، حالت تعمیرات، ثبت‌نام)

### 💎 کیف پول
- نمایش دارایی‌ها (ریال، تتر، بیت‌کوین، اتریوم، تون)
- تاریخچه تراکنش‌ها با فیلتر و جستجو
- انجام تراکنش جدید (واریز/برداشت/انتقال)
- نمودار هفتگی و تغییرات ۲۴ ساعته
- خروجی CSV
- کپی آدرس کیف پول با یک کلیک

## 🧪 چالش‌ها و راه‌حل‌های فنی

### ۱. Hydration Mismatch
- **مشکل:** `toLocaleString()` خروجی متفاوت در سرور و کلاینت داشت.
- **راه‌حل:** تابع `formatPrice` با `Intl.NumberFormat('fa-IR')` تعریف شد.

### ۲. خطای Watchpack (EACCES) در Termux
- **مشکل:** Next.js خطای `EACCES: permission denied` می‌داد.
- **راه‌حل:** تنظیم `watchOptions.ignored` در `next.config.mjs` و استفاده از `--webpack`.

### ۳. ناسازگاری ESM / CommonJS
- **مشکل:** `package.json` با `"type": "module"` و فایل‌های `module.exports`.
- **راه‌حل:** تبدیل به `export default` و استفاده از پسوند `.cjs` برای اسکریپت‌های موقت.

### ۴. اشغال پورت ۳۰۰۱
- **مشکل:** خطای `EADDRINUSE`.
- **راه‌حل:** `pkill -9 node` و تغییر پورت به ۳۰۰۲.

### ۵. مشکل زیرماژول‌های گیت
- **مشکل:** `fatal: not a git repository: apps/frontend/...`
- **راه‌حل:** `git submodule deinit` و پاک‌سازی `.gitmodules`.

### ۶. خطای Function Runtimes در Vercel
- **مشکل:** وجود `vercel.json` با runtime نامعتبر.
- **راه‌حل:** حذف تمام `vercel.json`های اضافی و استفاده از `framework: nextjs`.

### ۷. تداخل TypeScript
- **مشکل:** فایل‌های `tsconfig.json` و importهای `.tsx` باعث خطای بیلد می‌شدند.
- **راه‌حل:** تبدیل کامل پروژه به JavaScript و حذف TypeScript.

## 🚀 راه‌اندازی و استقرار

### پیش‌نیازها
- **Node.js** ≥ ۱۸ (در Termux: `pkg install nodejs`)
- **npm** یا **yarn**
- **Git** (برای push)

### نصب و اجرای لوکال
```bash
cd ~/tetrashop-projects/frontend
npm install
npm run dev
# فروشگاه روی http://localhost:3002 در دسترس خواهد بود
```

ساخت نسخهٔ تولید

```bash
npm run build
npm start
```

دیپلوی روی Vercel

1. مخزن را به Vercel متصل کنید.
2. در تنظیمات پروژه:
   · Root Directory: frontend
   · Build Command: npm run build
   · Output Directory: .next
3. Deploy کنید.

نکته: برای رفع محدودیت ۱۰۰ دیپلوی در روز، می‌توانید از Deploy Hook استفاده کنید:

```bash
curl -X POST https://api.vercel.com/v1/integrations/deploy/prj_xxxx/yyyy
```

📜 APIهای اصلی

مسیر متد توضیح
/api/auth/login POST ورود کاربران
/api/auth/register POST ثبت‌نام کاربر جدید
/api/auth/verify GET تأیید توکن
/api/wallet/balance GET موجودی کیف پول
/api/wallet/transaction POST ثبت تراکنش جدید
/api/wallet/history GET تاریخچه تراکنش‌ها
/api/admin/products GET/POST/PUT/DELETE مدیریت محصولات
/api/orders GET/POST/PATCH مدیریت سفارشات
/api/errors GET/POST لیست و رفع خطاها
/api/status GET وضعیت سرور (آپتایم، حافظه)
/api/blog GET مقالات وبلاگ
/api/blog/[slug] GET جزئیات مقاله
/api/faq GET سوالات متداول
/api/discounts/validate POST اعتبارسنجی کوپن تخفیف
/api/contact POST ارسال فرم تماس
