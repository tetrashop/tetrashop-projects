# 🚀 TetraShop Projects

پلتفرم جامع فروشگاهی با محصولات فیزیکی و دیجیتال، پنل مدیریت، کیف پول، بلاگ، خبرنامه، آنالیتیکس و ماژول‌های تعاملی.

## 🧩 ماژول‌های اصلی
- فروشگاه (Next.js + Zustand)
- پنل مدیریت با احراز هویت (admin/admin123)
- کیف پول ارزی و رمزارزی
- ربات بله، شطرنج، تحلیل احساسات، المپیک، سیستم خطا
- وبلاگ، خبرنامه، مقایسه محصولات، علاقه‌مندی‌ها
- داشبورد مالی و آنالیتیکس

## 🌐 دسترسی
- فروشگاه: https://tetrashop-projects-seven.vercel.app
- پنل مدیریت: /admin/login
