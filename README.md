# 🚀 TetraShop Projects — پلتفرم جامع فروشگاهی و محصولات دیجیتال

**مخزن اصلی پروژه‌های TetraShop**  
نسخه ۲.۱ — فروشگاه فیزیکی و دیجیتال، سرویس‌های ابری، ربات‌ها، هوش مصنوعی و ابزارهای مالی

---

## 📄 چکیده

پروژهٔ `tetrashop-projects` یک **مونورپو**ی بزرگ است که یک فروشگاه اینترنتی کامل (محصولات فیزیکی و دیجیتال) را به‌همراه **ده‌ها سرویس جانبی** – شامل ربات‌های پیام‌رسان، موتورهای شطرنج، سامانه‌های پردازش زبان طبیعی، تشخیص گفتار، OCR، ابزارهای مالی و پنل‌های مدیریتی – در خود جای داده است.  
هدف این مخزن ایجاد یک **اکوسیستم یکپارچه** برای عرضهٔ کالاهای نرم‌افزاری و سخت‌افزاری، همراه با **واسط‌های کاربری پیش‌نمایش (دموهای تعاملی)** و قابلیت فروش مستقیم می‌باشد.

این مستند **تمامی جنبه‌های فنّی**، چالش‌های پیش‌آمده در فرایند توسعه، راه‌حل‌های اعمال‌شده و دستورالعمل‌های راه‌اندازی را به‌صورت علمی تشریح می‌کند. همچنین برای **تک‌تک محصولات دیجیتال** مستندات جداگانه‌ای ارائه می‌دهد که در پوشهٔ مربوطه نیز موجود است.

---

## ۱. مقدمه

این مخزن حاصل **ادغام پروژه‌های مجزّا** (فروشگاه، ربات‌ها، NLP، شطرنج و …) در یک ساختار یکپارچه است.  
بخش اصلی فروشگاه با **Next.js 16** و **Tailwind CSS** پیاده‌سازی شده و از **Zustand** برای مدیریت حالت سبد خرید استفاده می‌کند.  
محصولات دیجیتال شامل **بیش از ۳۰ پروژهٔ مستقل** هستند که برای هرکدام یک **دموی تعاملی** در فروشگاه تعبیه شده است. هر محصول دیجیتال دارای یک **README تحلیلی** می‌باشد که جزئیات فنّی، چالش‌ها و راه‌حل‌های اختصاصی خود را توصیف می‌کند.

## ۴. چالش‌ها و راه‌حل‌های فنّی

### ۴.۱ خطای Hydration Mismatch
- **مشاهده:** `toLocaleString()` خروجی متفاوتی در سرور و مرورگر داشت.
- **راه‌حل:** تابع `formatPrice` با `Intl.NumberFormat('fa-IR')` تعریف شد.

### ۴.۲ خطای Watchpack (EACCES) در Termux
- **مشاهده:** Next.js خطای `EACCES: permission denied` می‌داد.
- **راه‌حل:** تنظیم `watchOptions.ignored` در `next.config.mjs` و استفاده از `--webpack`.

### ۴.۳ ناسازگاری ESM / CommonJS
- **مشاهده:** `package.json` با `"type": "module"` و فایل‌های `module.exports`.
- **راه‌حل:** تبدیل به `export default` و استفاده از پسوند `.cjs` برای اسکریپت‌های موقتی.

### ۴.۴ اشغال پورت
- **مشاهده:** خطای `EADDRINUSE`.
- **راه‌حل:** `pkill -9 node` و تغییر پورت به `3002`.

### ۴.۵ مشکل زیرماژول‌های گیت
- **مشاهده:** `fatal: not a git repository: apps/frontend/...`
- **راه‌حل:** `git submodule deinit` و پاک‌سازی `.gitmodules`.

### ۴.۶ یکپارچه‌سازی محصولات دیجیتال
- **چالش:** ۳۰+ پروژه باید در فروشگاه نمایش داده شوند.
- **راه‌حل:** اسکریپت `build-inventory.cjs` و فایل `digitalProducts.json`.

### ۴.۷ ساخت دموهای تعاملی
- **چالش:** هر محصول نیاز به پیش‌نمایش داشت.
- **راه‌حل:** کامپوننت‌های React با `dynamic import` و نگاشت در `DemoComponents.tsx`.

## ۵. راه‌اندازی پروژه

### پیش‌نیازها
- **Node.js** ≥ ۱۸ (در Termux: `pkg install nodejs`)
- **npm** یا **yarn**
- (اختیاری) **Python 3.9+** برای ربات‌ها و AI

### نصب و اجرای فروشگاه
```bash
cd ~/tetrashop-projects/frontend
npm install
npm run dev
# فروشگاه روی http://localhost:3002 در دسترس است
```

### ساخت نسخهٔ تولید
```bash
npm run build
npm start
```

## ۷. اسکریپت‌های خودکار (Automation)

- **`final_full.sh`** – نصب پکیج‌ها، تولید محصولات دیجیتال، ساخت دموها، رفع خطاهای پیکربندی و اجرای پروژه.
- **`master-setup.sh`** – نسخهٔ کامل‌تر با قابلیت resume.
- **`build-demos.cjs`** – تولید خودکار دموهای تعاملی.
- **`gen-readme.cjs`** – ساخت/بروزرسانی READMEهای تحلیلی.

برای اجرای یک‌بارهٔ همهٔ مراحل:
```bash
cd ~/tetrashop-projects/frontend
chmod +x final_full.sh
./final_full.sh
```

## ۹. جمع‌بندی و چشم‌انداز

پروژهٔ **TetraShop Projects** اکنون یک بستر کامل برای فروش کالاهای فیزیکی و دیجیتال است.  
دموهای تعاملی به خریداران کمک می‌کند پیش از خرید، محصولات نرم‌افزاری را آزمایش کنند.  

در آینده می‌توان:
- اتصال به درگاه پرداخت واقعی (زرین‌پال، Pay.ir)
- احراز هویت کاربران (NextAuth.js)
- تحویل خودکار محصول دیجیتال پس از خرید
- پنل مدیریت برای فروشنده
- بهینه‌سازی برای PWA
