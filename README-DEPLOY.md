# 🚀 راهنمای بهره‌برداری واقعی از TetraShop

این سند مراحل لازم برای تبدیل پروژه از حالت توسعه (شبیه‌سازی) به یک فروشگاه کاملاً واقعی را شرح می‌دهد.

## ۱. تنظیم متغیرهای محیطی در Vercel

وارد داشبورد Vercel شوید و در بخش **Settings → Environment Variables** مقادیر زیر را وارد کنید:

| نام متغیر | توضیح | اجباری؟ |
|-----------|-------|---------|
| `JWT_SECRET` | یک رشته تصادفی ۶۴ کاراکتری برای امضای توکن‌ها | بله |
| `MONGODB_URI` | آدرس اتصال به MongoDB Atlas (رایگان) | بله (برای ذخیره دائمی) |
| `ZARINPAL_MERCHANT_ID` | شناسه درگاه زرین‌پال | برای پرداخت آنلاین |
| `ZARINPAL_SANDBOX` | `true` برای تست، `false` برای واقعی | بله |
| `ZARINPAL_CALLBACK_URL` | آدرس بازگشت از درگاه | بله |
| `EMAIL_API_KEY` | کلید API سرویس Resend | برای ارسال ایمیل |
| `NEXT_PUBLIC_TON_ADDRESS` | آدرس عمومی کیف پول TON شما | برای نمایش موجودی |
| `TONCENTER_API_KEY` | کلید API رایگان از toncenter.com | برای دریافت داده واقعی |
| `CLOUDINARY_*` | اطلاعات ابری برای آپلود تصاویر | اختیاری |

**نکته:** اگر `MONGODB_URI` را تنظیم نکنید، داده‌ها همچنان در حافظه سرور ذخیره می‌شوند و با هر ری‌استارت پاک می‌شوند.

## ۲. دریافت کلیدهای API

### MongoDB Atlas (رایگان)
1. به [mongodb.com/atlas](https://www.mongodb.com/atlas) بروید.
2. یک کلاستر رایگان (Shared) بسازید.
3. یک کاربر پایگاه داده ایجاد کنید.
4. آدرس اتصال (Connection String) را کپی کرده و `<password>` را با رمز کاربر جایگزین کنید.
5. در Vercel به عنوان `MONGODB_URI` تنظیم کنید.

### زرین‌پال (درگاه پرداخت)
1. در [zarinpal.com](https://www.zarinpal.com) ثبت‌نام کنید.
2. از پنل کاربری، **Merchant ID** را دریافت کنید.
3. ابتدا `ZARINPAL_SANDBOX=true` بگذارید تا تست کنید.

### Resend (ایمیل)
1. در [resend.com](https://resend.com) ثبت‌نام کنید.
2. یک API Key بسازید.
3. دامنهٔ خود را تأیید کنید (یا از دامنهٔ آزمایشی استفاده کنید).

### TonCenter (کیف پول TON)
1. به [toncenter.com](https://toncenter.com) بروید.
2. یک API Key رایگان دریافت کنید (اختیاری – بدون آن هم کار می‌کند).

## ۳. تست نهایی

پس از تنظیم متغیرها، یک Deploy جدید در Vercel انجام دهید.  
سپس بررسی کنید:

- [ ] فروشگاه اصلی (`/`) بدون خطا بالا می‌آید.
- [ ] محصولات فیزیکی و دیجیتال نمایش داده می‌شوند.
- [ ] کیف پول (`/wallet`) موجودی واقعی TON را نشان می‌دهد.
- [ ] فرایند خرید (checkout) با فیلدهای ضروری کار می‌کند.
- [ ] پنل مدیریت (`/admin`) با احراز هویت در دسترس است.

## ۴. رفع مشکلات احتمالی

- **خطای CORS یا Network Error:** مطمئن شوید `NEXT_PUBLIC_SITE_URL` دقیقاً برابر با دامنهٔ اصلی باشد.
- **خطای MongoDB:** آدرس اتصال را چک کنید و مطمئن شوید IP فعلی شما در Atlas whitelist شده است.
- **خطای زرین‌پال:** ابتدا با sandbox تست کنید و callback URL را دقیقاً `/api/payment/verify` قرار دهید.
